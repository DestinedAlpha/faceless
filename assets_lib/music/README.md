# Background music (optional)

Drop royalty-free `.mp3` or `.m4a` tracks in this folder and they'll be used as
background music under the narration (ducked to `render.music.duck_db` in
`config.yaml`). Tracks are picked by a rotating index per run.

Keep it copyright-safe: use YouTube Audio Library, Pixabay Music, or similar
CC/royalty-free sources. If this folder is empty, videos render with narration only.
